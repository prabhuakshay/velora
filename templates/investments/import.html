Investment Import

Fill in the template from your statements, one Investment Event per row, then upload it. Velora checks every row and shows a preview; nothing changes until you confirm.

Rows on or before an Investment Account's Opening Balance date only build Lot history. A later Buy, Sell or Dividend that moves bank money is linked to the Transaction you already recorded for it. Rows already recorded are skipped, so uploading a file again is safe.

For a Merger, instrument_name names the new Instrument.
