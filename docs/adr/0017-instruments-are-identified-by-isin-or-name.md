# Instruments are identified by ISIN or by name, and the ISIN decides the Price Source

An Instrument is anything held in units with a Price per unit, so gold, bonds and unlisted shares fit beside mutual funds, stocks and ETFs. One with a real ISIN (format and checksum checked) is priced from AMFI or NSE; one without is identified by its unique name and priced by hand. The user never picks the Price Source. Kind is only a label. Making up a code in the ISIN field was set aside because a fake code looks like a real ISIN, which let a ticker such as `TEJASNET` become an unpriced manual Instrument without anyone noticing. Switching an Instrument from Manual to fetched once AMFI or NSE first lists it was also set aside, because the source would change under the user. Things with no units, such as a house, a fixed deposit or a PPF balance, stay Asset Accounts: as one unit at their whole value, Lots, Cost Basis and XIRR would mean nothing.
